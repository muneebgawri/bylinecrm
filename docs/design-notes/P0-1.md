# P0-1 — Repo + scaffold

**Package:** doc 49 §5, Phase 0. **Loop step 2 (design).**

## Data touched

None. The Prisma schema has a datasource and generator only; the baseline migration creates no tables. Tenancy
tables arrive with P0-2.

## Endpoints

`GET /health` → `HealthStatus` (`@bylinecrm/shared`): `{ status, db, redis, version }`. `db` is a real
`SELECT 1` through Prisma; `redis` is a real `PING`; `version` is the API package version. `status` is `ok`
only when both dependencies are. The endpoint is unauthenticated by design (a load balancer calls it) and
reveals nothing beyond liveness.

## Failure modes

| Failure                                 | Behaviour                                                                                                                                     |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| A required env var missing or malformed | The process exits at boot with the zod issue list; it never starts half-configured.                                                           |
| Postgres unreachable                    | `/health` answers `200` with `db: 'down'`, `status: 'degraded'`; the probe is bounded by a timeout so a hung socket cannot hang the endpoint. |
| Redis unreachable                       | Same shape with `redis: 'down'`.                                                                                                              |

`/health` answers `200` in every case because its job is to report, not to decide; the deployer reads the body.

## Not handled here

Authentication, tenancy and RLS (P0-2, P0-3), the web design system (P0-5), any domain model.

## Decisions made in this package

- **Own `ConfigModule`.** A zod schema parsed once at boot into a typed `Env` provider. `@nestjs/config` adds
  a second, untyped way to read the same values; one definition is the rule.
- **Ports** for the local stack: Postgres 5441, Redis 6391, API 3300, web 3301 — chosen to miss the other
  local stacks on this machine; CI uses the service containers' defaults through the same env names.
- **Majors** pinned to what the architect fixed (NestJS 11, Prisma 6, React Router 7, TypeScript 5). Newer
  majors exist for each; moving is a deliberate package, not a drive-by.
