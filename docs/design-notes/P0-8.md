# P0-8 — `packages/shared` lints with the shared config (#23, PR #24)

Before, the shared package's `lint` script was an `echo`: the one package every other one imports was
the one nothing checked. P0-8 gives it the same ESLint config as `api` and `web`
(`@bylinecrm/eslint-config/base`, `--max-warnings 0`), so a type or a constant that both sides read is
held to the same rules as the code that reads it. Zero findings on the sources at the time; no rule
weakened. The README gained the three commands a fresh worktree needs before `typecheck` (install,
build shared, generate the Prisma client) — the first trap every new builder had hit.
