# P0-9 — `visual:baseline` exits 0 on success and checks what it downloaded (#28, PR #41)

The baseline script failed after every _successful_ baseline job: `gh run download` refuses to
overwrite, and the script downloaded straight into `__snapshots__/`, which is never empty. P0-9
downloads into a fresh temporary directory, copies into `__snapshots__/` (the directory the visual
test reads through `snapshotPathTemplate`), and removes the temp dir in a `finally`. It refuses an
artifact holding anything but non-empty PNGs — a mismatch between the artifact and the test's
snapshot path can no longer put files where the test never reads them — and prints one summary line
(`N files updated (new, changed, unchanged)`). The poll for the dispatched run ignores runs that
existed before the dispatch, so it can never latch onto someone else's run on the same branch.
P0-12 (#82, PR #155) later replaced `gh run watch` with polling the run's real completion.
